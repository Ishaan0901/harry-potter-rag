# 📚 Harry Potter RAG

A Retrieval-Augmented Generation (RAG) chatbot that answers questions about a Harry Potter book using only the text of the book itself. Built with LangChain, ChromaDB, Hugging Face embeddings and Groq-hosted LLM inference.

> ✅ **Project status: complete.** This is the final version of the project. It is a working command-line RAG chatbot, and no further development is planned.

---

## ✨ Features

- **Grounded answers**: the model is instructed to answer only from retrieved book passages and never make things up.
- **Honest fallback**: if the answer isn't in the retrieved context, it replies *"I don't know based on the provided book."*
- **Local embeddings**: the book is embedded on your machine with `BAAI/bge-small-en-v1.5`, with no embedding API needed.
- **Persistent vector store**: index the book once, then query it as many times as you like.
- **Chat history**: the conversation so far is included in every prompt, so follow-up questions have context.
- **Fast inference**: answers are generated by `openai/gpt-oss-20b` through Groq.

---

## ⚙️ How It Works

The project has two phases: a one-time **ingestion** step and an interactive **chat** loop.

**Phase 1: Ingestion** (`backend/main.py`)

```
PDF → PyPDFLoader → RecursiveCharacterTextSplitter → HuggingFace Embeddings → ChromaDB (vectorStore/)
```

**Phase 2: Question answering** (`backend/app.py`)

```
Question ─► Retriever (Chroma) ─► Relevant chunks ─┐
                                                    ├─► Prompt (context + question + history) ─► Groq LLM ─► Answer
Chat history ──────────────────────────────────────┘
```

| Step             | Tool                             | Details                                                           |
| ---------------- | -------------------------------- | ----------------------------------------------------------------- |
| Document loading | `PyPDFLoader`                    | Loads `resources/harrypotter.pdf` page by page                    |
| Chunking         | `RecursiveCharacterTextSplitter` | `chunk_size=1000`, `chunk_overlap=100`                            |
| Embeddings       | `BAAI/bge-small-en-v1.5`         | Runs locally via `langchain-huggingface`                          |
| Vector store     | `Chroma`                         | Persisted to the `vectorStore/` directory                         |
| Retrieval        | `store.as_retriever()`           | Default similarity search (top 4 chunks)                          |
| Prompting        | `ChatPromptTemplate`             | Context, question and history combined with strict grounding rules |
| LLM              | `ChatGroq`                       | Model: `openai/gpt-oss-20b`                                       |

The answering pipeline is composed with LangChain's runnable (LCEL) syntax: a dict of `context`, `question` and `history` is piped into the prompt, then into the LLM.

## 🧰 Tech Stack

- **Python 3.10+**
- [LangChain](https://python.langchain.com/): `langchain`, `langchain-community`, `langchain-core`, `langchain-text-splitters`
- [ChromaDB](https://www.trychroma.com/): vector database
- [Hugging Face](https://huggingface.co/BAAI/bge-small-en-v1.5) (`sentence-transformers`, `langchain-huggingface`): embedding model
- [Groq](https://groq.com/) (`langchain-groq`): LLM inference
- [pypdf](https://pypdf.readthedocs.io/): PDF parsing
- `python-dotenv`: loads environment variables from `.env`

> `langgraph` is listed in `requirements.txt` but is not used in the final version of the code.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Ishaan0901/harry-potter-rag.git
cd harry-potter-rag
```

### 2. Create and activate a virtual environment

```bash
python -m venv venv

# Windows
venv\Scripts\activate

# macOS / Linux
source venv/bin/activate
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Add your Groq API key

Create a `.env` file in the project root:

```
GROQ_API_KEY=your_groq_api_key_here
```

You can get a free key from the [Groq console](https://console.groq.com/).

### 5. Add the book PDF

Create a `resources/` folder and place your PDF at:

```
resources/harrypotter.pdf
```

### 6. Build the vector store (run once)

Run all commands from the **project root**, because the paths in the scripts are relative:

```bash
python backend/main.py
```

This creates the `vectorStore/` folder. The first run also downloads the embedding model from Hugging Face, so it may take a few minutes.

### 7. Start chatting

```bash
python backend/app.py
```

```
Human: <your question>
```

Type `exit` or `bye` to quit.

## 📝 Known Limitations

- **Re-indexing creates duplicates.** Running `main.py` again adds the chunks to the existing store a second time. Delete the `vectorStore/` folder before re-indexing.
- **Retrieval uses only the latest question.** Chat history is passed to the LLM, but the vector search itself isn't rewritten using that history, so vague follow-ups may retrieve weaker context.
- **History is unbounded.** The full conversation is appended to every prompt, so very long sessions will grow the prompt size.
- **No source citations.** Answers don't show which pages they came from.
- **Copyright.** The PDF is excluded from version control because it is copyrighted material. Bring your own copy.
